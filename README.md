# 작은 길드 자동원정대

## Tiny Guild Auto Quest

컨트롤 없이 선택만으로 성장하는 관전형 방치 RPG 웹게임입니다. 작은 3인 파티가 자동으로 원정을 떠나고, 플레이어는 원정지·파티·전투 방침·업그레이드·장비·마을·환생을 선택하며 길드의 성장을 지켜봅니다.

## 주요 기능

- 상단 2D 디오라마 자동전투: 영웅 3명과 몬스터의 공격, 피해 숫자, 치명타, 회복, 보상 파티클
- 1초 단위 전투 tick과 스테이지 진행, 10스테이지 보스, 지역 해금
- 초록 숲, 오래된 광산, 고대 유적 3개 지역
- 방패병 로안, 궁수 미라, 검사 테오, 사제 세라, 도적 니아, 마법사 오르딘 6명
- 파티 3슬롯 편성 및 5종 전투 방침
- 24종 길드 업그레이드, 12종 장비 강화, 5종 마을 건물 성장
- 몬스터 처치 기록과 무료 도감 보너스
- 고대 유적 정복 후 1단계 환생 및 영구 명성 보너스
- 최대 120분, 온라인 예상 보상의 70%로 계산되는 오프라인 복귀 보상
- 숫자 성장, 마을 외형 변화, 자동전투 관전, 추천 문구, 첫 접속 안내
- 모바일 세로 화면 우선 반응형 UI, 키보드 포커스, reduced-motion 대응
- 외부 서버 없이 브라우저 `localStorage`에 저장

## 실행 방법

정적 서버로 프로젝트 루트의 `index.html`을 열면 됩니다.

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

브라우저에서 `http://localhost:4173`을 열어 플레이합니다. GitHub Pages 배포 workflow가 설정되어 있는 경우 배포된 페이지에서도 실행할 수 있습니다.

## 파일 구조

```text
.
├── index.html                         # 화면, 스타일, 게임 state와 전투 로직
├── README.md                          # 프로젝트 설명
└── .github/workflows/deploy-pages.yml # GitHub Pages 정적 배포
```

## 저장 방식

- 저장 키: `tiny-guild-auto-quest-save-v1`
- 골드, 명성, 룬, 재료, 영웅, 파티, 지역 진행, 업그레이드, 장비, 마을, 도감, 마지막 접속 시간, 설정을 하나의 state 객체로 저장합니다.
- 자동 저장은 5초마다 실행됩니다.
- 주요 선택 및 강화 버튼을 누른 직후 저장합니다.
- 탭을 숨기거나 페이지를 닫을 때도 저장합니다.
- 마지막 접속 이후의 오프라인 보상은 최대 120분까지 계산하고 온라인 예상 수익의 70%를 적용합니다.
- 브라우저 저장 데이터를 지우면 새 길드로 시작합니다.

## 향후 확장 아이디어

현재 버전에 포함되지 않은 확장 아이디어입니다.

- 서버 랭킹
- 계정 저장
- 더 많은 지역
- 더 많은 영웅
- 일일 도전
- 업적
